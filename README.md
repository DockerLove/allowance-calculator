# CoolantAdvisor

Веб-приложение для автоматического выбора смазочно-охлаждающей жидкости (СОЖ) и способа её подачи при фрезеровании.

Стек: React + TypeScript + Material UI (по курсу), Docker.

## Запуск

```bash
yarn install
yarn start          # http://localhost:3000
yarn test --watchAll=false
yarn build
```

Docker:

```bash
docker compose up --build   # http://localhost:3000
```

## Алгоритм

1. **Режим резания**: Vc = π·D·n/1000, Vf = fz·z·n, Q = ap·ae·Vf/1000, Pc = ap·ae·Vf·kc/60·10⁶.
2. **Потребности процесса** (шкала 0..10): охлаждение (теплонапряжённость материала, твёрдость, отношение Vc к ориентирной, производительность, стадия), смазка (налипание материала, стадия, Ra, низкая скорость, материал инструмента), удаление стружки (вид фрезерования).
3. **Жёсткие ограничения** (вариант исключается с объяснением): магний — без воды и аэрозолей; титан, никелевые сплавы, нержавейка, магний — без хлора; медь, никелевые сплавы, алюминий — без активной серы; керамика — только сухая обработка или воздух; оборудование станка; пользовательские настройки.
4. **Оценка 0..100** = технологическая пригодность (охлаждение, смазка, вымывание стружки) + предпочтения (стоимость, экология, защита от коррозии, по выбранному приоритету) ± поправки (термоциклирование твёрдого сплава при прерывистом резании, «сухие» материалы, коррозия, щёлочь для алюминия).
5. **Результат**: рейтинг, лучший вариант с обоснованием, способ подачи, концентрация, предупреждения, список исключённых вариантов.

Справочники (`src/Dictionaries`) можно расширять без изменения интерфейса.
